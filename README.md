# CPC
The Cabin Pressure Controler ML is supposed to controll the pressure within the cabine just like a normal cpc would do.
For this data was generated utilizing a Symulink Simulation which was then used to train a Neural Network. For the flight tests the cpc (GT) and the ml cpc (ML) are supposed to behave the same way.
